# feedback/ — 지적·교정 리포트

> 사용자에게 지적받은 내용을 1건 = 1파일로 기록한다. `memory/`(항상 적용)와 달리 **상황에 따라 판단해 적용**하는 노트다. (`~/.claude/convention/ai-process.md` §9.1)

## 파일 규칙

- 파일명: `YYYY-MM-DD-<kebab-요약>.md`
- 필수 항목: **무엇을 지적받았나**(증상/사용자 발언) / **왜 틀렸나**(근본 원인) / **어떻게 고치나** / **언제 적용하나**(적용 조건 — 무조건 적용 아님)
- 보편 규칙으로 굳어지면 이 폴더에 두지 말고 [memory/](../memory/) 또는 컨벤션 문서로 승격하고 원본은 삭제한다.
